# Dream

Three concepts for one target, at rising strangeness, from a fresh roll. No code until the user picks one. Use it when the user wants ideas, options, or "something nobody has seen".

## 1. Roll wide

Run `node <skill-dir>/scripts/roll.mjs --verb <verb> --object <object> --count 3`. Three rolls, nine-plus seeds. Read LEXICON.md's `Tried` list and skip anything on it.

## 2. Build three concepts

One at each of these levels, unless the user named a range:

- **Grounded** (strangeness 2). Familiar layout, strong material and rehearsal.
- **New** (strangeness 3 or 4). A metaphor that one approach teaches.
- **Wild** (strangeness 5). An object or scene in place of the control. Discovery is part of it.

Each concept must come from a different seed family (material, craft, phenomenon, mechanism, scene), so they differ in kind, not in degree. The wild one may break the product's world if it says so.

## 3. Write each concept

- **Name** in two or three words.
- **The picture** in one sentence a stranger can see in their head.
- **Five answers**, one line each.
- **Stages**: rest, approach, rehearse, commit, echo, one short line each.
- **Still** version for reduced motion, one line.
- **Cost**: browser features, performance risk, build effort (small, medium, large).
- **Risk**: what could make it unreadable or annoying.

Add an ASCII sketch when shape matters.

## 4. Ask

Present all three together, then ask the user to pick one, combine two, or roll again. With a structured question tool, put each concept's description inside its option, so the user can read what they are choosing. Without one, ask in plain text and stop.

## 5. Hand over

The chosen concept goes to `forge` step 3 with its spec. Record all three in LEXICON.md's `Tried` list with kept or rejected.
