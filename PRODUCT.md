# Product

## Platform

web

## Stack

Static HTML, CSS and JS for the showcase site, hosted on Cloudflare Workers static assets at stringless.baselashraf.com. No framework.

## Users

Developers and designers who build UI with coding agents such as Claude Code, Cursor and Codex. They are tired of agents shipping the same labeled rounded buttons. They try new skills from GitHub and decide in about a minute whether one is worth installing.

## Product Purpose

Stringless is an Agent Skills skill plus a small runtime. It makes coding agents design controls that show what they do through material, motion, form, space and time, so the controls need no text labels. Success: a visitor sees the output, understands the idea without reading much, and installs it.

## Positioning

Other design skills improve how a page looks. Stringless changes how a single control explains itself. Each control answers five questions without words (what it is, what it touches, what it will do, what it costs, where it is in time), and it rolls random seeds so agents invent new metaphors instead of repeating paper planes and trash cans.

## Operating Context

Visitors arrive from GitHub, X or Reddit, mostly on desktop, some on phones. Install happens in a terminal: `npx skills add BaselAshraf81/stringless` or the Claude Code plugin marketplace.

## Capabilities and Constraints

- 10 commands: init, lexicon, map, stage, forge, unstring, dream, guess, audit, tune.
- Runtime: about 18 KB gzipped, no dependencies, data attributes and CSS variables.
- Six working examples: ember delete, wet-ink save, frost-pane privacy, marble choice, vapor AI suggestions, slot-print export.
- Every control keeps an accessible name, works by keyboard and touch, and keeps its meaning with reduced motion.
- It is experimental. No usage numbers, customers or testimonials exist yet.
